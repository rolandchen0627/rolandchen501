📦 自動化撿貨申請流程整合工具
本專案為內部用自動化工具，用以整合台灣與海外地區的撿貨申請記錄，透過 API 串接內部系統、自動分配流水號，並上傳回主系統以完成每日作業流程。

🔧 功能簡介
📆 自動偵測當日是否為假日，避免非工作日進行作業

🔐 使用 OAuth2 憑證流程，自動取得授權 Token（已透過環境變數或遮蔽處理）

🔄 串接內部資料系統 API（如 CRM），查詢與更新自訂資料實體

🔍 查詢當日與次一工作日現有的最大撿貨流水號

🧮 自動分配流水號（TW/OS + 日期 + 三碼流水號）

🧾 根據申請時間與品項分類，區分「今日 / 明日」與「一般 / 特殊品項」
